# 关系代数

## 概述

关系代数是一种抽象的查询语言，它用关系运算来表达查询。关系代数的运算对象是关系，运算结果也是关系。

### 关系代数的分类

**传统集合运算**：
- 并、差、交、笛卡尔积

**专门关系运算**：
- 选择、投影、连接、除

## 传统集合运算

### 并运算（Union）

**定义**：两个关系的并运算结果包含两个关系中的所有元组，重复元组只保留一个。

**符号**：R ∪ S

**条件**：R和S必须是相容的（属性个数相同，对应属性的域相同）。

**示例**：

```
R:              S:              R ∪ S:
┌─────┬─────┐   ┌─────┬─────┐   ┌─────┬─────┐
│ A   │ B   │   │ A   │ B   │   │ A   │ B   │
├─────┼─────┤   ├─────┼─────┤   ├─────┼─────┤
│ 1   │ 2   │   │ 3   │ 4   │   │ 1   │ 2   │
│ 3   │ 4   │   │ 5   │ 6   │   │ 3   │ 4   │
└─────┴─────┘   └─────┴─────┘   │ 5   │ 6   │
                                └─────┴─────┘
```

### 差运算（Difference）

**定义**：两个关系的差运算结果包含属于R但不属于S的所有元组。

**符号**：R - S

**条件**：R和S必须是相容的。

**示例**：

```
R:              S:              R - S:
┌─────┬─────┐   ┌─────┬─────┐   ┌─────┬─────┐
│ A   │ B   │   │ A   │ B   │   │ A   │ B   │
├─────┼─────┤   ├─────┼─────┤   ├─────┼─────┤
│ 1   │ 2   │   │ 3   │ 4   │   │ 1   │ 2   │
│ 3   │ 4   │   │ 5   │ 6   │   └─────┴─────┘
└─────┴─────┘   └─────┴─────┘
```

### 交运算（Intersection）

**定义**：两个关系的交运算结果包含同时属于R和S的所有元组。

**符号**：R ∩ S

**条件**：R和S必须是相容的。

**示例**：

```
R:              S:              R ∩ S:
┌─────┬─────┐   ┌─────┬─────┐   ┌─────┬─────┐
│ A   │ B   │   │ A   │ B   │   │ A   │ B   │
├─────┼─────┤   ├─────┼─────┤   ├─────┼─────┤
│ 1   │ 2   │   │ 3   │ 4   │   │ 3   │ 4   │
│ 3   │ 4   │   │ 5   │ 6   │   └─────┴─────┘
└─────┴─────┘   └─────┴─────┘
```

### 笛卡尔积（Cartesian Product）

**定义**：两个关系的笛卡尔积结果包含R和S的所有可能的元组组合。

**符号**：R × S

**结果**：如果R有n个元组，S有m个元组，则R × S有n×m个元组。

**示例**：

```
R:              S:              R × S:
┌─────┐         ┌─────┐         ┌─────┬─────┬─────┐
│ A   │         │ C   │         │ A   │ B   │ C   │
├─────┤         ├─────┤         ├─────┼─────┼─────┤
│ 1   │         │ 3   │         │ 1   │ 2   │ 3   │
│ 2   │         └─────┘         │ 1   │ 2   │ 4   │
└─────┘                         │ 2   │ 5   │ 3   │
                                │ 2   │ 5   │ 4   │
                                └─────┴─────┴─────┘
```

## 专门关系运算

### 选择运算（Selection）

**定义**：从关系中选择满足给定条件的元组。

**符号**：σ<sub>条件</sub>(R)

**示例**：

```sql
-- 选择年龄大于18的学生
σ(age > 18)(students)

-- 选择计算机学院的男生
σ(department = '计算机学院' ∧ gender = '男')(students)
```

**SQL对应**：
```sql
SELECT * FROM students WHERE age > 18;
SELECT * FROM students WHERE department = '计算机学院' AND gender = '男';
```

### 投影运算（Projection）

**定义**：从关系中选择指定的属性列。

**符号**：π<sub>属性列表</sub>(R)

**示例**：

```sql
-- 选择学生的姓名和年龄
π(student_name, age)(students)

-- 选择所有不同的学院名称
π(department)(students)
```

**SQL对应**：
```sql
SELECT student_name, age FROM students;
SELECT DISTINCT department FROM students;
```

### 连接运算（Join）

**定义**：从两个关系的笛卡尔积中选择满足连接条件的元组。

**符号**：R ⋈<sub>条件</sub> S

**分类**：

#### 等值连接

**定义**：连接条件为两个属性相等。

**示例**：

```sql
-- 等值连接学生和选课表
students ⋈(students.student_id = enrollments.student_id) enrollments
```

**SQL对应**：
```sql
SELECT * FROM students, enrollments 
WHERE students.student_id = enrollments.student_id;
```

#### 自然连接

**定义**：等值连接的一种特殊情况，自动按相同属性名进行连接，并去除重复属性。

**符号**：R ⋈ S

**示例**：

```sql
-- 自然连接学生和选课表
students ⋈ enrollments
```

**SQL对应**：
```sql
SELECT * FROM students NATURAL JOIN enrollments;
```

#### 外连接

**定义**：即使不满足连接条件，也保留其中一个关系的所有元组。

**左外连接**：保留左关系的所有元组。
```sql
students ⟕ enrollments
```

**右外连接**：保留右关系的所有元组。
```sql
students ⟖ enrollments
```

**全外连接**：保留两个关系的所有元组。
```sql
students ⟗ enrollments
```

**SQL对应**：
```sql
SELECT * FROM students LEFT JOIN enrollments 
ON students.student_id = enrollments.student_id;
```

#### 除运算（Division）

**定义**：找出所有在R中与S中每个元组都匹配的元组。

**符号**：R ÷ S

**示例**：

```sql
-- 找出选修了所有课程的学生
students ÷ (SELECT student_id, course_id FROM enrollments)
```

## 关系代数表达式

### 复合运算

关系代数可以通过组合基本运算来表达复杂查询。

**示例**：查询选修了"数据库原理"课程的学生姓名

```sql
π(student_name)(
    σ(course_name = '数据库原理')(
        students ⋈ enrollments ⋈ courses
    )
)
```

**SQL对应**：
```sql
SELECT student_name FROM students
JOIN enrollments ON students.student_id = enrollments.student_id
JOIN courses ON enrollments.course_id = courses.course_id
WHERE course_name = '数据库原理';
```

### 运算顺序

关系代数的运算顺序：
1. 括号优先
2. 选择和投影优先于笛卡尔积
3. 笛卡尔积优先于并、差、交

## 关系代数与SQL

### 对应关系

| 关系代数 | SQL |
|----------|-----|
| σ<sub>条件</sub>(R) | SELECT * FROM R WHERE 条件 |
| π<sub>属性</sub>(R) | SELECT 属性 FROM R |
| R ∪ S | SELECT * FROM R UNION SELECT * FROM S |
| R - S | SELECT * FROM R EXCEPT SELECT * FROM S |
| R ∩ S | SELECT * FROM R INTERSECT SELECT * FROM S |
| R × S | SELECT * FROM R, S |
| R ⋈ S | SELECT * FROM R JOIN S ON 条件 |
| R ÷ S | 复杂查询 |

### 示例转换

**查询所有选修了课程的学生姓名**：

关系代数：
```sql
π(student_name)(students ⋈ enrollments)
```

SQL：
```sql
SELECT DISTINCT student_name FROM students
JOIN enrollments ON students.student_id = enrollments.student_id;
```

## 总结

关系代数是关系数据库的理论基础：
- 传统集合运算：并、差、交、笛卡尔积
- 专门关系运算：选择、投影、连接、除
- 关系代数可以表达各种复杂查询
- SQL是关系代数的实际应用
