# 主存

## 概述

主存（Main Memory）是计算机中用于存储程序和数据的部件，也称为内存。主存是CPU直接访问的存储设备，速度较快但容量有限。

### 主存的作用

1. **存储程序**：存储正在执行的程序
2. **存储数据**：存储程序运行所需的数据
3. **临时存储**：存储中间结果和堆栈数据

### 主存的特点

| 特性 | 描述 |
|------|------|
| 速度 | 较快（纳秒级） |
| 容量 | 较大（GB级） |
| 成本 | 较高 |
| 易失性 | 断电后数据丢失 |

## 主存的分类

### RAM（随机存取存储器）

**定义**：可以随机访问任意存储单元，读写速度快。

**分类**：

#### SRAM（静态随机存取存储器）

**工作原理**：
- 基于触发器存储数据
- 不需要刷新

**特点**：
- 速度快（访问时间1~10ns）
- 功耗低
- 成本高
- 容量小

**应用**：
- CPU缓存
- 高速寄存器

#### DRAM（动态随机存取存储器）

**工作原理**：
- 基于电容存储数据
- 需要定期刷新（每ms一次）

**特点**：
- 速度较慢（访问时间50~100ns）
- 功耗较高
- 成本低
- 容量大

**应用**：
- 主存
- 显存

**DRAM类型**：
- SDRAM：同步DRAM
- DDR SDRAM：双倍数据率SDRAM
- DDR2/3/4：更高版本的DDR

### ROM（只读存储器）

**定义**：数据只能读出，不能随意写入。

**分类**：

#### MROM（掩膜ROM）
- 数据在生产时固化
- 不能修改

#### PROM（可编程ROM）
- 可一次性编程
- 编程后不能修改

#### EPROM（可擦除可编程ROM）
- 可多次编程
- 使用紫外线擦除

#### EEPROM（电可擦除可编程ROM）
- 可多次编程
- 使用电信号擦除
- 可逐字节擦除

#### Flash Memory（闪存）
- 基于EEPROM技术
- 可多次编程
- 速度快

**应用**：
- BIOS
- 固件
- U盘
- SSD

## 主存的结构

### 存储单元

**定义**：存储一个二进制位（bit）的基本单元。

**结构**：
```
存储单元 = 存储元件 + 读写电路
```

### 存储体

**定义**：由多个存储单元组成的阵列。

**结构**：
```
        行地址
    ┌─────────────┐
    │ 00 01 02... │
列  │ 10 11 12... │
地  │ 20 21 22... │
址  │ ...         │
    └─────────────┘
```

### 地址寄存器（MAR）

**功能**：存储要访问的存储单元地址。

### 数据寄存器（MDR）

**功能**：存储从存储体读出的数据或要写入的数据。

### 地址译码器

**功能**：将地址转换为存储单元的选择信号。

**结构**：
```
地址输入 → 地址译码器 → 存储单元选择信号
```

## 主存的工作原理

### 读操作

**步骤**：
1. CPU将地址送入MAR
2. MAR将地址发送到地址总线
3. 地址译码器译码，选择存储单元
4. 存储单元将数据送入数据总线
5. MDR从数据总线接收数据
6. CPU从MDR读取数据

### 写操作

**步骤**：
1. CPU将地址送入MAR
2. CPU将数据送入MDR
3. MAR将地址发送到地址总线
4. MDR将数据发送到数据总线
5. 地址译码器译码，选择存储单元
6. 存储单元从数据总线接收数据

### 时序控制

**同步时序**：
- 所有操作由统一的时钟信号控制

**异步时序**：
- 操作之间通过握手信号协调

## 主存的扩展

### 位扩展

**目的**：增加字长。

**方法**：将多个存储芯片并联。

**示例**：用4片1M×1位芯片组成1M×4位存储器
```
芯片1：位0
芯片2：位1
芯片3：位2
芯片4：位3
```

### 字扩展

**目的**：增加存储容量。

**方法**：将多个存储芯片串联。

**示例**：用2片1M×8位芯片组成2M×8位存储器
```
芯片1：地址0~1M-1
芯片2：地址1M~2M-1
```

### 字位扩展

**目的**：同时增加字长和容量。

**方法**：结合位扩展和字扩展。

**示例**：用4片1M×4位芯片组成2M×8位存储器
```
芯片1+2：地址0~1M-1，位0~7
芯片3+4：地址1M~2M-1，位0~7
```

## 主存的性能指标

### 存储容量

**定义**：主存能够存储的二进制数据总量。

**单位**：
- 位（bit）
- 字节（Byte）
- 千字节（KB）
- 兆字节（MB）
- 吉字节（GB）
- 太字节（TB）

### 存取时间

**定义**：从CPU发出读写请求到完成读写操作所需的时间。

**单位**：纳秒（ns）

### 存取周期

**定义**：两次连续访问主存之间的最小时间间隔。

**关系**：存取周期 ≥ 存取时间

### 带宽

**定义**：单位时间内主存能够传输的数据量。

**计算公式**：
```
带宽 = 存储容量 / 存取周期
```

## 主存与CPU的连接

### 地址总线

**功能**：传输内存地址。

**宽度**：决定最大可寻址空间。

**示例**：32位地址总线可寻址4GB空间。

### 数据总线

**功能**：传输数据。

**宽度**：决定一次传输的数据量。

**示例**：64位数据总线一次可传输8字节。

### 控制总线

**功能**：传输控制信号。

**信号类型**：
- 读信号（RD）
- 写信号（WR）
- 地址有效信号（AEN）
- 等待信号（WAIT）

## 主存的层次结构

### 层次结构概述

```
CPU寄存器 ── 高速缓存(Cache) ── 主存 ── 辅存
    ↑           ↑              ↑          ↑
  速度最快    速度较快        速度较慢    速度最慢
  容量最小    容量较小        容量较大    容量最大
  成本最高    成本较高        成本较低    成本最低
```

### 局部性原理

**时间局部性**：
- 最近访问的数据可能很快再次被访问

**空间局部性**：
- 访问某个数据时，其附近的数据也可能被访问

### 缓存技术

**原理**：利用局部性原理，将常用数据存入Cache。

**命中率**：
```
命中率 = Cache命中次数 / 总访问次数
```

## 总结

主存是计算机的核心存储部件，其性能直接影响计算机的整体性能。理解主存的分类、结构和工作原理对于设计高性能计算机系统至关重要。
