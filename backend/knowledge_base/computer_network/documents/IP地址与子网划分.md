# IP地址与子网划分

## IP地址概述

IP地址是互联网中设备的唯一标识，用于在网络中定位和通信。IPv4地址由32位二进制数组成，通常表示为点分十进制形式（如192.168.1.1）。

### IP地址分类

IPv4地址根据第一个字节分为五类：

- **A类地址**：1-126，用于大型网络
- **B类地址**：128-191，用于中型网络
- **C类地址**：192-223，用于小型网络
- **D类地址**：224-239，用于组播
- **E类地址**：240-255，保留用于实验

### 子网划分

子网划分是将一个大的IP网络分成多个小网络的过程，通过子网掩码实现。

**子网掩码**：用于区分网络地址和主机地址，由连续的1和0组成。

**CIDR表示法**：使用斜杠加数字表示子网掩码中1的个数，如192.168.1.0/24。

### 子网划分示例

假设拥有一个C类网络192.168.1.0/24，需要划分成4个子网：

1. 确定需要的子网位数：2^n >= 4，所以n=2
2. 子网掩码变为/26（24+2）
3. 每个子网有64个地址（2^6），其中可用主机数为62个（减去网络地址和广播地址）

**VLSM（可变长子网掩码）**：允许在同一网络中使用不同长度的子网掩码，提高地址利用率。

### IPv6简介

IPv6地址由128位组成，采用冒号分隔的十六进制表示，如2001:0db8:85a3:0000:0000:8a2e:0370:7334。IPv6解决了IPv4地址枯竭的问题，并提供更好的安全性和性能。

## 总结

IP地址与子网划分是网络层的核心概念，掌握这些知识对于设计和管理网络至关重要。
