# 以太网与MAC地址

## 以太网概述

以太网是目前最广泛使用的局域网技术，由施乐公司在1973年发明。

### 以太网特点

- **共享介质**：早期使用总线型拓扑，多个设备共享同一传输介质
- **CSMA/CD**：载波监听多路访问/冲突检测
- **帧格式**：定义了数据帧的结构

### CSMA/CD工作原理

1. **监听**：发送前监听介质是否空闲
2. **发送**：如果空闲，发送数据
3. **检测**：发送过程中检测是否发生冲突
4. **退避**：如果检测到冲突，停止发送，等待随机时间后重发

## MAC地址

### MAC地址概述

MAC（Media Access Control）地址是网络接口的物理地址，用于在局域网中标识设备。

### MAC地址结构

MAC地址由48位二进制数组成，通常表示为十六进制形式，如00-1A-2B-3C-4D-5E。

- **前24位**：厂商标识符（OUI），由IEEE分配
- **后24位**：设备标识符，由厂商分配

### MAC地址类型

1. **单播地址**：用于一对一通信
2. **广播地址**：FF-FF-FF-FF-FF-FF，用于一对所有通信
3. **组播地址**：用于一对多通信

## 以太网帧格式

### IEEE 802.3帧格式

1. **前导码**：7字节，用于同步
2. **帧起始定界符**：1字节，标识帧的开始
3. **目的MAC地址**：6字节
4. **源MAC地址**：6字节
5. **长度/类型**：2字节
6. **数据**：46-1500字节
7. **FCS**：4字节，帧校验序列

### 最大传输单元（MTU）

以太网的MTU为1500字节，超过此长度的数据需要分片。

## 以太网发展

### 以太网标准

| 标准 | 速率 | 介质 |
|------|------|------|
| 10BASE-T | 10Mbps | 双绞线 |
| 100BASE-TX | 100Mbps | 双绞线 |
| 1000BASE-T | 1Gbps | 双绞线 |
| 10GBASE-T | 10Gbps | 双绞线 |

### 全双工模式

现代以太网支持全双工模式，可以同时发送和接收数据，消除了CSMA/CD的冲突问题。

## 总结

以太网是局域网的基础技术，MAC地址是设备在局域网中的唯一标识。
