# 评分标准（Evaluation Rubric）

本文件定义 A/B/C/D/E 五组对照实验的评分维度与判分规则，供复现核验。

## 实验组别

| 组别 | 配置 | 验证目标 |
|------|------|----------|
| A | 纯 LLM | 基线，无检索无画像 |
| B | LLM + RAG | 检索是否提升事实正确性 |
| C | LLM + RAG + 审查 Agent | 审查能否发现错误并触发重写 |
| D | LLM + RAG + 审查 + 学生画像 | 完整系统，画像是否提升个性化 |
| E | LLM + RAG + 画像（无审查） | 消融组，证明审查 Agent 的边际贡献 |

## 评分维度（每题 0-5 分，由独立 LLM 评分员给出）

### 1. factual_score 事实正确性
- 5：完全正确，无事实错误，概念准确
- 4：基本正确，有微小瑕疵
- 3：核心正确但存在细节错误
- 2：部分正确，有明显错误
- 1：大部分错误
- 0：完全错误或答非所问

### 2. citation_score 引用准确性
- 5：引用来源且来源完全支撑回答
- 3：引用来源但支撑不充分
- 0：无引用来源（A 组无检索，恒 0）

### 3. personalization_score 个性化匹配度
- 5：回答明显适配学生水平与偏好（如给基础薄弱学生用图解、给编程型学生用代码）
- 3：部分适配
- 1：通用回答，未体现个性化
- 0：完全不适配（A/B/C 组无画像注入，恒 0）

## 审查 Agent 触发重写规则（C/D 组）

- 审查员对 `factual` 项评分 < 4.0 时触发重写
- 最多重写 2 次
- 每次重写后重新审查
- 记录最终重试次数到 `retries` 字段

## 消融对比逻辑

| 对比 | 证明 |
|------|------|
| D vs C | 学生画像对个性化匹配度的提升 |
| D vs E | 审查 Agent 对事实正确性的提升 |
| C vs B | 审查 + 重写对事实正确性的提升 |
| B vs A | RAG 检索对事实正确性 + 引用准确性的提升 |

## 复现要求

- 模型与温度固定在 `model_config.json`
- 每组每题重复 N 次（`--repeat N`），报告均值±标准差
- 所有 LLM 原始输出保存到 `raw_outputs_*.json`，可交叉核验
- 评分员独立于审查员，避免评分偏向

## 学生画像（三类反事实画像）

| 画像 | 掌握度 | 常见错误 | 偏好资源 |
|------|--------|----------|----------|
| 基础薄弱型 | 35% | 混淆 cwnd 与 rwnd | 动画+图解 |
| 计算易错型 | 55% | RTT 计算漏项 | 公式推导+例题 |
| 偏好编程型 | 70% | 概念能用但说不清 | 代码仿真+实验 |

画像按 `hash(question_id) % 3` 轮换分配，保证三类学生在题目上均匀分布且可复现。
