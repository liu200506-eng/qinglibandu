=====================================
MagicStudy 知识库迁移包
=====================================

文件结构：
├── knowledge_export.json    # 知识点数据（32科目，532知识点）
├── import_knowledge.py      # 数据导入脚本（使用主项目数据库）
└── README.txt               # 本说明文件

=====================================
使用方法
=====================================

步骤1：确保主项目数据库已初始化
启动主项目后，数据库会自动创建

步骤2：导入知识点数据
cd backend/migration_package
python import_knowledge.py

=====================================
数据说明
=====================================
- 科目数：32个（高中9科 + 大学23科）
- 知识点数：896个
- 数据格式：JSON
- 包含：知识树结构、难度、描述等框架信息
- 注意：讲义/习题/闪卡内容需通过AI生成或手动填充

=====================================
注意事项
=====================================
- 本迁移包使用主项目的 database.py 和 models/database_models.py
- 不需要单独配置数据库连接
- 导入脚本会自动连接到主项目的 magicstudy.db 数据库
