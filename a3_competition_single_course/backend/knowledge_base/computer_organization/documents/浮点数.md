# 浮点数

## 概述

浮点数是计算机中表示实数的一种方法，其小数点位置可以浮动。浮点数由阶码和尾数两部分组成，类似于科学计数法。

### 浮点数表示形式

```
N = M × R^E
```

其中：
- **M（尾数）**：表示有效数字
- **R（基数）**：通常为2、10或16
- **E（阶码）**：表示小数点的位置

### 浮点数的特点

- 表示范围大
- 精度有限
- 需要规范化处理

## IEEE 754标准

### 标准概述

IEEE 754是国际电气与电子工程师协会制定的浮点数标准，被广泛应用于计算机系统中。

### 单精度浮点数（32位）

```
┌─────────┬─────────────┬──────────────────────┐
│ 符号位S │   阶码E(8位)  │      尾数M(23位)      │
├─────────┼─────────────┼──────────────────────┤
│ 第31位  │ 第30~23位   │      第22~0位        │
└─────────┴─────────────┴──────────────────────┘
```

**表示范围**：
- **符号位S**：0表示正数，1表示负数
- **阶码E**：偏移量为127，实际阶码 = E - 127
- **尾数M**：隐含最高位1，实际尾数 = 1.M

### 双精度浮点数（64位）

```
┌─────────┬───────────────┬──────────────────────────────┐
│ 符号位S │   阶码E(11位)   │        尾数M(52位)          │
├─────────┼───────────────┼──────────────────────────────┤
│ 第63位  │ 第62~52位     │         第51~0位            │
└─────────┴───────────────┴──────────────────────────────┘
```

**表示范围**：
- **符号位S**：0表示正数，1表示负数
- **阶码E**：偏移量为1023，实际阶码 = E - 1023
- **尾数M**：隐含最高位1，实际尾数 = 1.M

## 浮点数的表示

### 规范化表示

为了保证浮点数表示的唯一性，IEEE 754要求尾数必须规范化，即尾数的绝对值在[1, 2)范围内。

**示例**：将0.125表示为单精度浮点数
```
0.125 = 1.0 × 2^(-3)

符号位S = 0 (正数)
阶码E = -3 + 127 = 124 = 01111100
尾数M = 000...000 (因为1.0的小数部分为0)

最终表示：0 01111100 00000000000000000000000
```

### 特殊值

IEEE 754定义了几种特殊值：

| 阶码E | 尾数M | 表示值 |
|-------|-------|--------|
| 0 | 0 | 0 |
| 0 | ≠0 | 非规范化数 |
| 1~254 | 任意 | 规范化数 |
| 255 | 0 | ±∞ |
| 255 | ≠0 | NaN（非数值） |

### 非规范化数

当阶码E=0且尾数M≠0时，表示非规范化数，用于表示接近0的小数值。

**特点**：
- 尾数不隐含1，实际尾数 = 0.M
- 阶码固定为-126（单精度）或-1022（双精度）

## 浮点数运算

### 加法运算

**步骤**：
1. 对阶：将两个数的阶码对齐
2. 尾数相加：将对齐后的尾数相加
3. 规范化：将结果规范化
4. 舍入：处理精度问题
5. 溢出判断：检查结果是否溢出

**示例**：X=0.5，Y=0.25
```
X = 1.0 × 2^(-1) = 0 01111110 00000000000000000000000
Y = 1.0 × 2^(-2) = 0 01111101 00000000000000000000000

步骤1：对阶
Y的阶码小，需要右移1位
Y = 0.1 × 2^(-1) = 0 01111110 10000000000000000000000

步骤2：尾数相加
1.0 + 0.1 = 1.1 (二进制)

步骤3：规范化
1.1 × 2^(-1)，已经规范化

步骤4：舍入
无需舍入

步骤5：溢出判断
未溢出

结果：0 01111110 10000000000000000000000 = 0.75
```

### 乘法运算

**步骤**：
1. 符号位处理：结果符号 = 两个数符号的异或
2. 阶码相加：结果阶码 = 两个数阶码相加
3. 尾数相乘：两个尾数相乘
4. 规范化：将结果规范化
5. 舍入：处理精度问题
6. 溢出判断：检查结果是否溢出

### 除法运算

**步骤**：
1. 符号位处理：结果符号 = 两个数符号的异或
2. 阶码相减：结果阶码 = 被除数阶码 - 除数阶码
3. 尾数相除：被除数尾数 ÷ 除数尾数
4. 规范化：将结果规范化
5. 舍入：处理精度问题
6. 溢出判断：检查结果是否溢出

## 舍入方法

IEEE 754定义了四种舍入方法：

### 1. 就近舍入（Round to Nearest）

- 向最接近的可表示值舍入
- 如果距离相等，向偶数舍入

### 2. 向零舍入（Round Toward Zero）

- 截断多余的位，向零方向舍入

### 3. 向下舍入（Round Toward Negative Infinity）

- 向负无穷方向舍入

### 4. 向上舍入（Round Toward Positive Infinity）

- 向正无穷方向舍入

## 浮点误差

### 误差来源

1. **表示误差**：某些十进制数无法精确表示为二进制浮点数
2. **运算误差**：运算过程中可能产生舍入误差
3. **溢出**：结果超出表示范围

### 典型问题

**示例**：0.1 + 0.2 ≠ 0.3
```
0.1 = 0.0001100110011...(二进制无限循环)
0.2 = 0.0011001100110...(二进制无限循环)
0.1 + 0.2 = 0.0100110011001... ≈ 0.30000000000000004
```

### 避免方法

1. 使用高精度数据类型
2. 避免直接比较浮点数相等
3. 使用适当的舍入方法

## 浮点数与定点数的比较

| 特性 | 定点数 | 浮点数 |
|------|--------|--------|
| 表示范围 | 较小 | 较大 |
| 精度 | 均匀 | 不均匀（靠近0精度高） |
| 运算复杂度 | 简单 | 复杂 |
| 存储需求 | 固定 | 固定 |
| 适用场景 | 整数运算、小数位数固定 | 科学计算、工程计算 |

## 总结

IEEE 754标准是现代计算机浮点数表示的基础，理解其原理对于编写高性能数值计算程序至关重要。浮点数运算需要注意精度问题和溢出处理。
