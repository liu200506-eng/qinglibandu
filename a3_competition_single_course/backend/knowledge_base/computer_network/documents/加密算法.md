# 加密算法

## 加密概述

加密是将明文转换为密文的过程，用于保护数据的机密性。

### 加密算法分类

1. **对称加密**：加密和解密使用相同的密钥
2. **非对称加密**：加密和解密使用不同的密钥
3. **哈希函数**：将任意长度数据转换为固定长度摘要

## 对称加密

### 对称加密特点

- **速度快**：加密解密效率高
- **密钥管理困难**：需要安全地分发和管理密钥
- **适合大量数据**：常用于加密数据传输

### 常见对称加密算法

1. **DES**：
   - 56位密钥
   - 已被破解，不再安全
   
2. **AES**：
   - 128/192/256位密钥
   - 目前最安全的对称加密算法
   - 广泛应用于各种场景

3. **3DES**：
   - 三重DES加密
   - 比DES更安全，但速度较慢

### 对称加密模式

1. **ECB（电子密码本）**：相同明文产生相同密文，不安全
2. **CBC（密码分组链接）**：使用IV，安全性较高
3. **CFB（密码反馈）**：流式加密，适合实时通信
4. **OFB（输出反馈）**：流式加密，与CFB类似

## 非对称加密

### 非对称加密特点

- **安全性高**：私钥不需要传输
- **速度慢**：加密解密效率低
- **适合密钥交换**：常用于交换对称密钥

### 常见非对称加密算法

1. **RSA**：
   - 基于大数分解难题
   - 广泛应用于数字签名和密钥交换
   - 密钥长度通常为2048或4096位

2. **ECC（椭圆曲线加密）**：
   - 基于椭圆曲线数学难题
   - 相同安全级别下，密钥更短
   - 适合移动设备和物联网

3. **DSA**：
   - 专门用于数字签名
   - 基于离散对数难题

### 非对称加密工作流程

1. 生成公钥和私钥对
2. 公钥公开，私钥保密
3. 使用公钥加密，私钥解密
4. 使用私钥签名，公钥验证

## 哈希函数

### 哈希函数特点

- **单向性**：无法从哈希值反推原始数据
- **唯一性**：不同输入产生不同哈希值（理想情况）
- **固定长度**：无论输入多长，输出长度固定

### 常见哈希函数

1. **MD5**：
   - 128位输出
   - 已被破解，不再安全

2. **SHA-1**：
   - 160位输出
   - 已被破解，不再安全

3. **SHA-2**：
   - SHA-256（256位）、SHA-512（512位）
   - 目前安全，广泛应用

4. **SHA-3**：
   - 新一代哈希函数
   - 抗量子攻击

## 总结

对称加密用于数据加密，非对称加密用于密钥交换和签名，哈希函数用于数据完整性验证。
