# FTP与邮件协议

## FTP概述

FTP（File Transfer Protocol）是用于在网络上传输文件的协议。

### FTP特点

- **基于TCP**：使用两个TCP连接（控制连接和数据连接）
- **明文传输**：用户名和密码以明文传输
- **主动/被动模式**：支持两种数据连接模式

### FTP连接类型

1. **控制连接**：用于传输命令，端口21
2. **数据连接**：用于传输文件数据

### FTP主动模式

1. 客户端打开随机端口，发送PORT命令
2. 服务器从端口20主动连接客户端的指定端口

### FTP被动模式

1. 客户端发送PASV命令
2. 服务器打开随机端口，告知客户端
3. 客户端连接服务器的指定端口

### SFTP

SFTP（SSH File Transfer Protocol）是安全的FTP版本，通过SSH加密传输。

## 邮件协议概述

电子邮件系统使用多种协议协同工作。

### SMTP

SMTP（Simple Mail Transfer Protocol）用于发送邮件。

- 端口：25（明文）或465（SSL）
- 工作方式：客户端→服务器→服务器→接收方

### POP3

POP3（Post Office Protocol）用于接收邮件。

- 端口：110（明文）或995（SSL）
- 工作方式：客户端下载邮件后，服务器默认删除邮件

### IMAP

IMAP（Internet Message Access Protocol）用于接收邮件。

- 端口：143（明文）或993（SSL）
- 工作方式：邮件保留在服务器上，客户端同步操作

### POP3与IMAP对比

| 特性 | POP3 | IMAP |
|------|------|------|
| 邮件存储 | 下载到本地 | 保留在服务器 |
| 多设备同步 | 不支持 | 支持 |
| 离线访问 | 支持 | 部分支持 |
| 服务器负载 | 低 | 高 |

## 邮件传输流程

1. 发件人使用MUA（邮件用户代理）编写邮件
2. MUA使用SMTP发送邮件到发件人服务器
3. 发件人服务器使用SMTP转发到收件人服务器
4. 收件人使用MUA通过POP3或IMAP接收邮件

## 总结

FTP用于文件传输，邮件协议用于电子邮件系统，都是互联网中重要的应用层协议。
