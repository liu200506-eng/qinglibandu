# HTTP与HTTPS

## HTTP概述

HTTP（Hypertext Transfer Protocol）是用于在Web上传输超文本的协议。

### HTTP特点

- **无状态**：服务器不保存客户端的状态信息
- **明文传输**：数据以明文形式传输，不安全
- **基于TCP**：建立在TCP连接之上

### HTTP请求方法

| 方法 | 用途 |
|------|------|
| GET | 获取资源 |
| POST | 提交数据 |
| PUT | 更新资源 |
| DELETE | 删除资源 |
| HEAD | 获取资源头部 |
| OPTIONS | 获取服务器支持的方法 |

### HTTP状态码

| 状态码 | 类别 | 说明 |
|--------|------|------|
| 1xx | 信息性 | 请求已接收，继续处理 |
| 2xx | 成功 | 请求成功处理 |
| 3xx | 重定向 | 需要进一步操作 |
| 4xx | 客户端错误 | 请求有错误 |
| 5xx | 服务器错误 | 服务器处理失败 |

## HTTPS概述

HTTPS（HTTP Secure）是HTTP的安全版本，通过SSL/TLS加密传输数据。

### HTTPS特点

- **加密传输**：数据使用对称加密传输
- **身份认证**：通过数字证书验证服务器身份
- **数据完整性**：防止数据篡改

### HTTPS工作流程

1. **建立TCP连接**：客户端与服务器建立TCP连接
2. **SSL/TLS握手**：
   - 客户端发送支持的加密套件
   - 服务器发送数字证书
   - 客户端验证证书
   - 协商对称密钥
3. **加密传输**：使用对称密钥加密数据传输
4. **关闭连接**：关闭SSL/TLS连接和TCP连接

### HTTPS与HTTP的对比

| 特性 | HTTP | HTTPS |
|------|------|-------|
| 端口 | 80 | 443 |
| 安全性 | 明文传输 | 加密传输 |
| 速度 | 较快 | 较慢（加密开销） |
| 证书 | 不需要 | 需要CA证书 |

## HTTP/2

HTTP/2是HTTP的新版本，提供更好的性能：

- **多路复用**：一个TCP连接上同时传输多个请求/响应
- **头部压缩**：减少头部传输大小
- **服务器推送**：服务器主动推送资源

## 总结

HTTPS通过加密和认证提供了安全的Web通信，是现代网站的标配。
