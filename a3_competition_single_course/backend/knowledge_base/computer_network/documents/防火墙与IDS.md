# 防火墙与IDS

## 防火墙概述

防火墙是一种网络安全设备，用于控制进出网络的流量。

### 防火墙的作用

1. **访问控制**：允许或拒绝特定流量
2. **网络隔离**：隔离内部网络和外部网络
3. **日志记录**：记录网络活动
4. **NAT**：网络地址转换

### 防火墙类型

1. **包过滤防火墙**：
   - 工作在网络层
   - 根据IP地址、端口、协议过滤
   - 速度快，功能简单

2. **应用层防火墙**：
   - 工作在应用层
   - 可以检查应用层数据
   - 功能强大，速度较慢

3. **状态检测防火墙**：
   - 跟踪连接状态
   - 只允许响应内部发起的连接
   - 安全性较高

### 防火墙规则

防火墙规则通常包含：

- **源IP地址**
- **目标IP地址**
- **源端口**
- **目标端口**
- **协议**（TCP/UDP/ICMP）
- **动作**（允许/拒绝）

### 防火墙部署位置

1. **网络边界**：连接内部网络和互联网
2. **内部网络**：隔离不同部门
3. **服务器前面**：保护重要服务器

## IDS概述

IDS（Intrusion Detection System）是一种检测网络入侵行为的系统。

### IDS的作用

1. **异常检测**：检测异常的网络行为
2. **攻击识别**：识别已知的攻击模式
3. **实时告警**：及时通知管理员
4. **日志记录**：记录入侵事件

### IDS类型

1. **NIDS（网络入侵检测系统）**：
   - 监控网络流量
   - 检测网络层和传输层的攻击
   - 不影响网络性能

2. **HIDS（主机入侵检测系统）**：
   - 安装在主机上
   - 检测主机层面的攻击
   - 可以检测文件篡改

### IDS检测方法

1. **特征检测**：
   - 基于已知攻击模式
   - 准确率高，漏报率低
   - 无法检测未知攻击

2. **异常检测**：
   - 基于正常行为模型
   - 可以检测未知攻击
   - 误报率较高

## IPS概述

IPS（Intrusion Prevention System）是IDS的升级版，可以主动阻止攻击。

### IPS与IDS的区别

| 特性 | IDS | IPS |
|------|-----|-----|
| 响应方式 | 被动检测，告警 | 主动阻止攻击 |
| 部署方式 | 旁路部署 | 在线部署 |
| 对网络影响 | 无 | 可能影响性能 |
| 安全性 | 检测 | 检测+阻止 |

## 总结

防火墙用于防止未授权访问，IDS用于检测入侵行为，IPS用于主动阻止攻击，三者共同构成网络安全防线。
