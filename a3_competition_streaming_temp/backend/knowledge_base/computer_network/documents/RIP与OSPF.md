# RIP与OSPF

## RIP协议

RIP（Routing Information Protocol）是一种距离向量路由协议。

### RIP特点

- 使用跳数作为度量标准，最大跳数为15
- 默认每30秒发送一次路由更新
- 支持水平分割和毒性逆转
- 适用于小型网络

### RIP版本

- **RIPv1**：不支持VLSM，使用广播发送更新
- **RIPv2**：支持VLSM，使用组播发送更新，支持认证

### RIP工作过程

1. 路由器启动时，初始化路由表
2. 定期向邻居发送完整路由表
3. 接收邻居的路由更新
4. 使用Bellman-Ford算法更新路由表

## OSPF协议

OSPF（Open Shortest Path First）是一种链路状态路由协议。

### OSPF特点

- 使用带宽作为度量标准
- 支持大型网络，最多可支持数千个路由器
- 收敛速度快
- 支持VLSM和CIDR
- 使用组播发送更新

### OSPF区域

为了支持大型网络，OSPF将网络划分为多个区域：

- **骨干区域（Area 0）**：必须存在，连接其他区域
- **非骨干区域**：连接到骨干区域

### OSPF工作过程

1. 建立邻居关系
2. 交换链路状态信息（LSA）
3. 构建链路状态数据库（LSDB）
4. 使用Dijkstra算法计算最短路径
5. 生成路由表

### RIP与OSPF对比

| 特性 | RIP | OSPF |
|------|-----|------|
| 算法类型 | 距离向量 | 链路状态 |
| 度量标准 | 跳数 | 带宽 |
| 最大跳数 | 15 | 无限制 |
| 收敛速度 | 慢 | 快 |
| 适用网络 | 小型 | 大型 |

## 总结

RIP适用于小型网络，配置简单；OSPF适用于大型网络，功能强大但配置复杂。
