📝 Subtitles

Hello students. Today we analyze TCP slow start in depth.
Sender maintains congestion window cwnd.
Initially cwnd is set to 1 MSS.
After each RTT, cwnd approximately doubles.
Exponential growth probes available bandwidth quickly.
Slow start threshold ssthresh controls growth.
When cwnd >= ssthresh, switch to congestion avoidance.
Congestion avoidance: cwnd grows linearly.
This prevents network congestion.
On packet loss, ssthresh = cwnd/2.
cwnd resets to 1, re-enter slow start.
