# 安全

## 一、数据库安全概述

数据库安全是保护数据库免受非法访问、修改和破坏的措施。

### 安全威胁类型

1. **未授权访问**：未经许可访问数据库
2. **数据泄露**：敏感数据被窃取或泄露
3. **数据篡改**：数据被非法修改
4. **拒绝服务**：数据库服务被恶意中断

## 二、访问控制

### 用户管理

1. **用户认证**
   - 用户名和密码
   - 双因素认证
   - 数字证书

2. **用户授权**
   - 基于角色的访问控制（RBAC）
   - 细粒度权限控制
   - 最小权限原则

### SQL权限

- **对象权限**：对表、视图等对象的操作权限
- **语句权限**：创建数据库对象的权限
- **角色**：一组权限的集合

## 三、数据加密

### 加密类型

1. **传输加密**
   - SSL/TLS加密传输
   - 防止数据在传输过程中被窃取

2. **存储加密**
   - 数据在存储时加密
   - 防止数据库文件被直接读取

3. **字段级加密**
   - 对敏感字段单独加密
   - 如密码、身份证号等

### 加密算法

- **对称加密**：AES、DES
- **非对称加密**：RSA
- **哈希函数**：MD5、SHA-256

## 四、审计与监控

### 审计日志

- 记录所有数据库操作
- 包括操作类型、操作者、时间、结果
- 用于安全审计和故障排查

### 实时监控

- 监控数据库性能
- 检测异常访问模式
- 预警安全威胁

## 五、安全最佳实践

1. 定期更新数据库软件
2. 使用强密码策略
3. 限制数据库访问端口
4. 定期备份数据
5. 实施最小权限原则
6. 定期安全审计
7. 加密敏感数据
8. 监控数据库活动
