# ER模型

## 一、ER模型的概念

ER（Entity-Relationship）模型是一种概念数据模型，用于描述现实世界的实体、属性和实体之间的关系。

### ER模型的组成

1. **实体（Entity）**
   - 客观存在并可相互区别的事物
   - 用矩形表示

2. **属性（Attribute）**
   - 实体所具有的特性
   - 用椭圆形表示

3. **联系（Relationship）**
   - 实体之间的关联
   - 用菱形表示

## 二、实体的分类

### 强实体
- 可以独立存在的实体
- 例如：学生、课程

### 弱实体
- 依赖于其他实体存在的实体
- 需要借助强实体的主键才能唯一标识
- 例如：选课记录依赖于学生和课程

## 三、属性的分类

### 简单属性和复合属性
- **简单属性**：不可再分的属性，如姓名、年龄
- **复合属性**：可以分解为多个属性，如地址（省、市、区、街道）

### 单值属性和多值属性
- **单值属性**：每个实体只有一个值，如学号
- **多值属性**：每个实体可以有多个值，如电话号码

### 派生属性
- 由其他属性计算得出的属性
- 如年龄可以由出生日期计算得出

## 四、联系的类型

### 一对一联系（1:1）
- 一个实体集中的每个实体最多与另一个实体集中的一个实体联系
- 例如：一个学生只有一个学号，一个学号只对应一个学生

### 一对多联系（1:N）
- 一个实体集中的每个实体可以与另一个实体集中的多个实体联系
- 例如：一个班级有多个学生，一个学生只属于一个班级

### 多对多联系（M:N）
- 两个实体集中的实体之间可以相互联系多次
- 例如：一个学生可以选多门课程，一门课程可以被多个学生选修

## 五、ER图的绘制步骤

1. 识别实体
2. 确定实体的属性
3. 确定实体之间的联系
4. 确定联系的类型
5. 绘制ER图

## 六、ER模型向关系模型的转换

### 实体的转换
- 每个实体转换为一个关系（表）
- 实体的属性转换为表的列
- 实体的主键转换为表的主键

### 联系的转换
- **1:1联系**：可以将一方的主键作为另一方的外键
- **1:N联系**：将一方的主键作为多方的外键
- **M:N联系**：创建一个新的关系表，包含双方的主键
