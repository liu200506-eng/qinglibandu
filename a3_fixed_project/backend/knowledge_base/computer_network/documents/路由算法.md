# 路由算法

## 路由概述

路由是指将数据包从源主机转发到目标主机的过程。路由算法是路由器用来决定最佳路径的规则和方法。

### 路由算法分类

1. **静态路由**：由管理员手动配置，适用于小型网络
2. **动态路由**：路由器自动学习网络拓扑并更新路由表

### 距离向量算法

距离向量算法基于Bellman-Ford算法，路由器定期向邻居发送自己的路由表。

**特点**：
- 每个路由器只知道到邻居的距离
- 收敛速度较慢
- 容易产生计数到无穷问题

**解决方法**：
- 水平分割：不向来源方向发送路由信息
- 毒性逆转：将来源方向的路由度量设为无穷大

### 链路状态算法

链路状态算法基于Dijkstra算法，每个路由器维护完整的网络拓扑图。

**特点**：
- 每个路由器知道整个网络的拓扑
- 收敛速度快
- 计算复杂度较高

**工作步骤**：
1. 发现邻居并建立邻接关系
2. 测量到邻居的延迟
3. 向全网广播链路状态信息
4. 构建网络拓扑图
5. 使用Dijkstra算法计算最短路径

### 路径向量算法

路径向量算法结合了距离向量和链路状态的优点，常用于BGP协议。

**特点**：
- 记录到达目的地的完整路径
- 可以避免路由环路
- 支持策略路由

## 总结

路由算法是网络层的核心技术，不同算法适用于不同规模和需求的网络。
