# NAT与VPN

## NAT概述

NAT（Network Address Translation）是一种将私有IP地址转换为公有IP地址的技术。

### NAT的作用

1. **节省IP地址**：多个内部设备共享一个公有IP
2. **增强安全性**：隐藏内部网络结构
3. **解决IP地址冲突**

### NAT类型

1. **静态NAT**：一对一映射，固定私有IP到公有IP
2. **动态NAT**：多对多映射，从地址池分配公有IP
3. **PAT（端口地址转换）**：一对多映射，通过端口区分不同连接

### PAT工作原理

1. 内部主机发送数据包到外部
2. NAT设备将源IP替换为公有IP，源端口替换为随机端口
3. NAT设备记录映射关系
4. 外部返回数据包时，NAT设备根据端口号转发到正确的内部主机

## VPN概述

VPN（Virtual Private Network）是一种通过公共网络建立安全私有连接的技术。

### VPN的作用

1. **远程访问**：允许远程用户安全访问企业网络
2. **站点间连接**：连接多个地理位置的网络
3. **数据加密**：保护数据传输安全

### VPN协议

1. **IPsec**：
   - 工作在网络层
   - 提供数据加密和认证
   - 支持隧道模式和传输模式

2. **SSL/TLS VPN**：
   - 工作在应用层
   - 通过浏览器访问
   - 无需安装客户端

3. **PPTP**：
   - 工作在数据链路层
   - 微软开发
   - 加密强度较低

4. **L2TP**：
   - 工作在数据链路层
   - 需要配合IPsec使用

### VPN工作流程

1. 建立安全隧道
2. 数据加密传输
3. 隧道内传输私有数据
4. 到达目的地后解密

## 总结

NAT解决了IP地址短缺问题，VPN提供了安全的远程访问能力。
