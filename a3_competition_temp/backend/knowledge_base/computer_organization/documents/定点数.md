# 定点数

## 概述

定点数是计算机中表示整数和小数的一种方法，其小数点位置固定不变。根据小数点位置的不同，定点数可分为定点整数和定点小数。

### 定点整数

小数点固定在数值的最右边，表示整数。

**示例**：
```
假设字长为8位，小数点位置：
  0 1 0 1 0 1 0 1 .
  ↑整数部分         ↑小数点
```

### 定点小数

小数点固定在数值的最左边，表示纯小数。

**示例**：
```
假设字长为8位，小数点位置：
  . 0 1 0 1 0 1 0 1
  ↑小数点 ↑小数部分
```

## 原码

### 定义

原码是最简单的机器数表示法，最高位为符号位，0表示正数，1表示负数，其余位表示数值的绝对值。

### 原码表示

**定点整数原码**：
```
[X]原 = X,          0 ≤ X < 2^(n-1)
[X]原 = 2^(n-1) + |X|,   -2^(n-1) < X ≤ 0
```

**定点小数原码**：
```
[X]原 = X,          0 ≤ X < 1
[X]原 = 1 + |X|,    -1 < X ≤ 0
```

### 示例

**例1**：字长n=8，X=+1010101
```
[X]原 = 0 1 0 1 0 1 0 1
```

**例2**：字长n=8，X=-1010101
```
[X]原 = 1 1 0 1 0 1 0 1
```

### 原码特点

- 符号位直观，容易理解
- 0有两种表示：[+0]原 = 00000000，[-0]原 = 10000000
- 加减法运算复杂，需要判断符号

## 反码

### 定义

反码是原码的一种变形，正数的反码与原码相同，负数的反码是对原码除符号位外的各位取反。

### 反码表示

**定点整数反码**：
```
[X]反 = X,          0 ≤ X < 2^(n-1)
[X]反 = (2^n - 1) + X,   -2^(n-1) < X ≤ 0
```

**定点小数反码**：
```
[X]反 = X,          0 ≤ X < 1
[X]反 = (2 - 2^-(n-1)) + X,    -1 < X ≤ 0
```

### 示例

**例1**：字长n=8，X=+1010101
```
[X]反 = 0 1 0 1 0 1 0 1  (与原码相同)
```

**例2**：字长n=8，X=-1010101
```
[X]原 = 1 1 0 1 0 1 0 1
[X]反 = 1 0 1 0 1 0 1 0  (除符号位外取反)
```

### 反码特点

- 0有两种表示：[+0]反 = 00000000，[-0]反 = 11111111
- 反码是求补码的中间步骤

## 补码

### 定义

补码是计算机中最常用的机器数表示法，正数的补码与原码相同，负数的补码是对原码除符号位外的各位取反后加1。

### 补码表示

**定点整数补码**：
```
[X]补 = X,          0 ≤ X < 2^(n-1)
[X]补 = 2^n + X,    -2^(n-1) ≤ X < 0
```

**定点小数补码**：
```
[X]补 = X,          0 ≤ X < 1
[X]补 = 2 + X,      -1 ≤ X < 0
```

### 示例

**例1**：字长n=8，X=+1010101
```
[X]补 = 0 1 0 1 0 1 0 1  (与原码相同)
```

**例2**：字长n=8，X=-1010101
```
[X]原 = 1 1 0 1 0 1 0 1
[X]反 = 1 0 1 0 1 0 1 0
[X]补 = 1 0 1 0 1 0 1 1  (反码加1)
```

### 补码特点

- 0只有一种表示：[0]补 = 00000000
- 加减法可以统一为加法运算
- 符号位可以参与运算

## 移码

### 定义

移码主要用于表示浮点数的阶码，它是补码的符号位取反。

### 移码表示

**定点整数移码**：
```
[X]移 = 2^(n-1) + X,    -2^(n-1) ≤ X < 2^(n-1)
```

### 示例

**例1**：字长n=8，X=+1010101
```
[X]补 = 0 1 0 1 0 1 0 1
[X]移 = 1 1 0 1 0 1 0 1  (符号位取反)
```

**例2**：字长n=8，X=-1010101
```
[X]补 = 1 0 1 0 1 0 1 1
[X]移 = 0 0 1 0 1 0 1 1  (符号位取反)
```

### 移码特点

- 移码表示的数可以直接比较大小
- 常用于浮点数的阶码表示

## 定点运算

### 补码加法

```
[X+Y]补 = [X]补 + [Y]补 (mod 2^n)
```

**示例**：X=+10，Y=-6
```
[X]补 = 00001010
[Y]补 = 11111010
[X+Y]补 = 00001010 + 11111010 = 00000100 (mod 256)
X+Y = +4 ✓
```

### 补码减法

```
[X-Y]补 = [X]补 + [-Y]补 (mod 2^n)
```

**示例**：X=+10，Y=+6
```
[X]补 = 00001010
[-Y]补 = 11111010
[X-Y]补 = 00001010 + 11111010 = 00000100 (mod 256)
X-Y = +4 ✓
```

## 溢出判断

### 单符号位判断

当两个同号数相加时，如果结果的符号位与加数不同，则发生溢出。

### 双符号位判断

使用两位符号位，00表示正数，11表示负数，01表示上溢，10表示下溢。

**示例**：X=+63，Y=+63（字长8位）
```
[X]补 = 00 0111111
[Y]补 = 00 0111111
[X+Y]补 = 01 111110 (双符号位为01，上溢)
```

## 总结

| 码制 | 正数 | 负数 | 0的表示 | 用途 |
|------|------|------|---------|------|
| 原码 | 符号位为0 | 符号位为1 | 两种 | 直观表示 |
| 反码 | 同原码 | 除符号位取反 | 两种 | 求补码 |
| 补码 | 同原码 | 反码加1 | 一种 | 加减法运算 |
| 移码 | 补码符号位取反 | 补码符号位取反 | 一种 | 浮点数阶码 |
