# ALU与CU

## 概述

CPU主要由运算器和控制器两部分组成：
- **ALU（算术逻辑单元）**：负责执行算术运算和逻辑运算
- **CU（控制单元）**：负责控制指令的执行流程

## ALU（算术逻辑单元）

### 功能

ALU是CPU的核心运算部件，主要执行以下运算：

1. **算术运算**：加法、减法、乘法、除法
2. **逻辑运算**：与、或、非、异或
3. **移位运算**：左移、右移、循环移位
4. **比较运算**：比较大小、判断相等

### 结构

```
        ┌─────────────┐
        │   输入数据  │
        └──────┬──────┘
               │
        ┌──────▼──────┐
        │   选择器    │
        └──────┬──────┘
               │
        ┌──────▼──────┐
        │   运算单元  │
        │  (加法器等) │
        └──────┬──────┘
               │
        ┌──────▼──────┐
        │   输出结果  │
        └─────────────┘
```

### 加法器

#### 半加器

半加器只考虑两个1位二进制数相加，不考虑低位进位。

**逻辑表达式**：
```
S = A ⊕ B
C = A · B
```

#### 全加器

全加器考虑两个1位二进制数相加和低位进位。

**逻辑表达式**：
```
S = A ⊕ B ⊕ C_in
C_out = (A · B) + (A · C_in) + (B · C_in)
```

#### 多位加法器

将多个全加器级联，实现多位二进制数相加。

**串行进位加法器**：
```
FA1──FA2──FA3──...──FAn
```

**超前进位加法器**：
通过提前计算进位，提高加法速度。

### 算术运算

#### 补码加法
```
[X+Y]补 = [X]补 + [Y]补
```

#### 补码减法
```
[X-Y]补 = [X]补 + [-Y]补
```

#### 乘法运算
- **原码乘法**：符号位单独处理，数值位相乘
- **补码乘法**：布斯算法

#### 除法运算
- **原码除法**：恢复余数法、不恢复余数法
- **补码除法**：加减交替法

### 逻辑运算

| 运算 | 表达式 | 真值表 |
|------|--------|--------|
| 与 | F = A · B | 只有A=1且B=1时F=1 |
| 或 | F = A + B | A=1或B=1时F=1 |
| 非 | F = A' | 取反 |
| 异或 | F = A ⊕ B | A≠B时F=1 |
| 同或 | F = A ⊙ B | A=B时F=1 |

### 移位运算

#### 算术移位
- **左移**：符号位不变，低位补0
- **右移**：符号位不变，高位补符号位

#### 逻辑移位
- **左移**：低位补0
- **右移**：高位补0

#### 循环移位
- **循环左移**：移出的位从右端移入
- **循环右移**：移出的位从左端移入

## CU（控制单元）

### 功能

控制单元负责协调整个CPU的工作，主要功能包括：

1. **取指令**：从主存中取出指令
2. **指令译码**：分析指令的操作码和操作数
3. **执行指令**：控制ALU和其他部件执行指令
4. **访存**：访问主存读取或写入数据
5. **写回**：将结果写回寄存器

### 控制方式

#### 同步控制
- 所有操作由统一的时钟信号控制
- 每个指令周期包含固定数量的时钟周期

**特点**：
- 结构简单
- 效率较低（复杂指令需要更多时间）

#### 异步控制
- 操作之间通过握手信号协调
- 每个操作完成后发送信号通知下一个操作

**特点**：
- 效率高
- 结构复杂

#### 联合控制
- 大部分操作采用同步控制
- 某些操作采用异步控制

### 微程序控制

#### 微指令与微程序
- **微指令**：控制计算机各部件完成一个基本操作的指令
- **微程序**：由一系列微指令组成，对应一条机器指令

#### 微程序控制器结构
```
        ┌─────────────────┐
        │   微程序存储器  │
        └────────┬────────┘
                 │
        ┌────────▼────────┐
        │   微指令寄存器  │
        └────────┬────────┘
                 │
        ┌────────▼────────┐
        │   微地址形成器  │
        └────────┬────────┘
                 │
        ┌────────▼────────┐
        │   控制信号生成器│
        └─────────────────┘
```

#### 微指令格式

**水平型微指令**：
```
┌──────────────────────────────────────┐
│  操作控制字段  │  顺序控制字段        │
└──────────────────────────────────────┘
```

**垂直型微指令**：
```
┌─────────┬──────────────────────────┐
│ 操作码   │   操作数                  │
└─────────┴──────────────────────────┘
```

### 硬布线控制

#### 基本原理
- 使用逻辑电路直接生成控制信号
- 控制信号由指令操作码、时序信号等组合逻辑生成

#### 硬布线控制器结构
```
        ┌───────────────┐
        │   指令译码器  │
        └───────┬───────┘
                │
        ┌───────▼───────┐
        │   时序产生器  │
        └───────┬───────┘
                │
        ┌───────▼───────┐
        │   组合逻辑电路│
        └───────┬───────┘
                │
        ┌───────▼───────┐
        │   控制信号    │
        └───────────────┘
```

#### 特点

| 特性 | 微程序控制 | 硬布线控制 |
|------|-----------|-----------|
| 灵活性 | 高 | 低 |
| 执行速度 | 慢 | 快 |
| 设计复杂度 | 低 | 高 |
| 维护难度 | 低 | 高 |

## CPU执行过程

### 指令周期

一条指令的执行过程称为指令周期，通常包括以下阶段：

1. **取指阶段**（IF）：从主存取出指令
2. **译码阶段**（ID）：分析指令操作码
3. **执行阶段**（EX）：执行指令操作
4. **访存阶段**（MEM）：访问主存（如果需要）
5. **写回阶段**（WB）：将结果写回寄存器

### 时序控制

#### 时钟周期
- CPU的基本时间单位
- 由晶振频率决定

#### 机器周期
- 完成一个基本操作的时间
- 包含多个时钟周期

#### 指令周期
- 执行一条指令的时间
- 包含多个机器周期

## 总结

ALU和CU是CPU的两大核心部件：
- ALU负责数据运算，包括算术、逻辑和移位运算
- CU负责指令执行的控制和协调
- 微程序控制和硬布线控制是两种主要的控制方式
